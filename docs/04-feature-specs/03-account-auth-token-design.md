# Halo iOS 账户、认证与 Token 充值原型设计

日期：2026-07-28

## 目标

在现有 `prototype.html` 中补齐个人产品需要的常规账户闭环，让演示可以完整覆盖：

- 账户中心。
- Token 余额与充值。
- 切换账号。
- 退出登录。
- 密码登录。
- 验证码登录。
- 忘记密码。
- 修改密码。

本阶段仍是交互原型。短信、邮件、Apple 登录、支付、身份验证和服务端会话均使用明确的模拟状态，不接入真实后端。

## 设计原则

1. 沿用现有 iOS 分组设置、紧凑导航栏、白色卡片和单一靛蓝强调色。
2. 登录前页面不显示四栏主导航；登录成功后回到对话页。
3. 账户、安全和资金类操作使用独立页面，临时确认使用底部弹层。
4. 危险操作必须二次确认；验证码、密码和充值必须包含失败与成功反馈。
5. 页面标题保持居中，按钮尺寸、图标和安全区遵循现有原型规范。

## 信息架构

### 设置页

设置页增加两个分组：

- 账户与安全
  - 账户中心。
  - 登录与安全。
  - 修改密码。
  - 切换账号。
- Token 与支付
  - Token 余额。
  - 充值 Token。
  - 消费记录。

设置页底部保留独立的红色「退出登录」入口。删除账户仍是单独的高风险操作，不与退出登录合并。

### 账户中心

展示：

- 头像、昵称、Halo ID、绑定手机号和邮箱。
- 当前登录方式与最近登录设备。
- iCloud 同步状态。
- 修改密码、切换账号和退出登录入口。

### Token 中心

展示：

- 当前 Token 余额。
- 预计可支持的文字、语音和视频用量。
- 推荐充值套餐与自定义金额。
- 支付方式选择。
- 最近充值和消费记录。

点击充值套餐后进入确认页；确认支付后显示模拟成功页并更新页面余额。支付失败状态提供重新支付与更换方式。

## 认证流程

### 密码登录

输入手机号、邮箱或 Halo ID，以及密码。支持显示/隐藏密码、记住账号、忘记密码和切换验证码登录。

演示版采用宽松登录规则：账号和密码只要非空即可进入产品，不校验账号格式、密码强度或真实凭证。

原型校验：

- 账号为空时提示输入账号。
- 密码少于 8 位时提示格式不正确。
- 合法输入后模拟登录成功，进入对话页。

### 验证码登录

输入手机号或邮箱，点击获取验证码。按钮进入 60 秒倒计时的模拟状态。验证码采用六位分格输入。

演示版允许填写任意非空联系方式，并接受任意六位数字验证码。

原型校验：

- 联系方式为空或格式明显错误时不发送。
- 验证码不足六位时不能继续。
- 输入六位验证码后模拟登录成功。

### 忘记密码

采用三步页面内流程：

1. 输入绑定手机号或邮箱。
2. 输入六位验证码。
3. 设置并确认新密码。

完成后返回密码登录，并提示密码已更新。

### 修改密码

登录状态下从「账户与安全」进入：

- 输入当前密码。
- 输入新密码。
- 再次确认新密码。

新密码至少 8 位，且两次输入必须一致。提交成功后提示其他设备会话已退出，当前设备保持登录。

### 切换账号

账号列表展示当前账号、两个最近使用账号和「登录其他账号」：

- 点击其他已有账号时显示 Face ID / 密码确认模拟。
- 点击「登录其他账号」进入登录页。
- 切换成功后更新设置页资料卡并返回对话页。

### 退出登录

点击后打开确认弹层，说明：

- 本机未同步草稿会保留。
- Agent、记忆和朋友圈成果保留在账户中。
- 可选择「取消」或红色「退出登录」。

确认后进入登录页，不直接删除任何数据。

## 原型状态

单文件原型维护以下本地状态：

- `authState`：当前是否登录、登录方式和当前账号。
- `accountState`：账号列表和当前账号 ID。
- `tokenState`：余额、选中套餐、支付方式和交易记录。
- `verificationState`：验证码发送状态与倒计时。
- `passwordFlowState`：忘记密码当前步骤。

刷新页面后恢复默认 mock 数据，不做跨刷新持久化。

## 异常与反馈

- 表单错误显示在对应字段下方，不只使用 Toast。
- 获取验证码提供倒计时、重新发送和发送失败反馈。
- 登录失败提供账号或密码错误状态。
- Token 支付提供处理中、成功和失败三种状态。
- 切换账号和退出登录使用确认弹层。
- 所有提交按钮在必填信息不足时呈禁用状态或给出明确错误。

## 验收标准

1. 设置页可以进入账户中心、Token 中心、修改密码和切换账号。
2. 退出登录必须经过确认，确认后进入登录页。
3. 密码登录与验证码登录可以相互切换并完成模拟登录。
4. 忘记密码可以完成三步流程并返回登录页。
5. 修改密码包含当前密码、新密码、确认密码及错误反馈。
6. Token 充值可以选择套餐、支付方式并展示成功或失败结果。
7. 切换账号可以选择已有账号或进入其他账号登录。
8. 登录前页面不显示主导航，登录后恢复四个主页面。
9. 新增页面无横向滚动条、无内容裁切，标题稳定居中。
10. 所有关键按钮均有页面变化、状态变化、弹层或 Toast 反馈。

## 不在本阶段范围

- 真实账户注册与服务端会话。
- 真实短信或邮件验证码。
- 真实 Apple 登录。
- 真实支付、退款、发票和订阅。
- 实名认证、青少年模式和家长控制。
- 多端登录设备的真实下线能力。
