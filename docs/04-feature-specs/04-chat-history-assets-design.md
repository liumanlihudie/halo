# Halo 聊天记录与文件资产设计

日期：2026-07-28
状态：已确认（2026-07-29 补充搜索与卡片布局）

## 1. 产品决策

Halo 不增加独立“文件管理”主页面，也不增加第五个主 Tab。用户按照即时通讯习惯，从具体会话的资料页进入“查找聊天记录”，再按内容类型查看文件。

底层仍使用统一的本地资产库保存用户导入文件和模型生成成果，但该资产库是基础设施，不直接暴露成传统文件管理器。

```text
用户界面：按会话查找聊天记录
系统内部：统一 AssetRepository
设置页面：只负责空间统计和清理
```

## 2. 入口与分类

### 2.1 单聊

```text
单 Agent 对话
→ 右上角「…」
→ 聊天资料
→ 查找聊天记录
```

### 2.2 群聊

```text
多 Agent 群聊
→ 右上角「…」
→ 群资料
→ 查找聊天记录
```

### 2.3 分类

```text
全部｜图片与视频｜文件｜链接｜AI 成果
```

- **全部**：按时间倒序显示所有可检索内容。
- **图片与视频**：用户发送、Agent 返回和模型生成的图片、GIF、视频。
- **文件**：PDF、Word、Excel、PPT、Markdown、代码、压缩包等。
- **链接**：网页、引用来源和模型生成的可访问链接。
- **AI 成果**：Agent 生成的图片、视频、音频、报告、表格、PPT、代码包、群聊总结和研究成果卡。

“AI 成果”是业务分类，不是新的物理文件类型。一项资产可以同时属于“图片与视频”和“AI 成果”。

## 3. 展示与预览

### 3.1 搜索入口

从“查找聊天记录”进入后，页面只展示一个 iOS 风格搜索框。用户尚未输入关键词时，下方保持空白，不显示历史记录、筛选标签、推荐词或最近搜索。

输入关键词后进入搜索结果态：

- 结果只使用纵向列表，不使用卡片或相册网格。
- 按时间倒序排列，展示结果类型、日期、发送者或来源。
- 文件名、消息文字、Agent 名称和来源标题中的匹配词使用高亮背景。
- 点击结果打开对应内容，并可继续定位到原消息。
- 无结果时显示轻量空状态，并保留当前关键词。

搜索底层使用 SQLite FTS5。`MessageSearchIndex` 以消息、文件、链接和 AI 成果为检索文档，索引 `messageText`、`displayName`、`agentName`、`sourceTitle` 和 `conversationTitle`。查询使用 FTS5 `MATCH`，结果通过 `snippet()` 生成带高亮标记的摘要；中文首版使用 SQLite `unicode61` 分词与前缀查询，后续可替换为更强的中文 tokenizer，不改变页面协议。

### 3.2 分类入口

用户从聊天详情点击“图片与视频”“文件”“链接”或“AI 成果”时，进入同一个聊天记录页面的分类模式。分类模式不展示搜索结果列表，而是展示日期分段卡片：

```text
今天
[ 卡片 ][ 卡片 ][ 卡片 ]

昨天
[ 卡片 ][ 卡片 ]

7 月 24 日
[ 卡片 ][ 卡片 ][ 卡片 ]
```

- 图片与视频：三列相册网格；视频显示时长、播放图标和生成状态。
- 文件：两列文件卡；显示文件类型 SVG、文件名、大小和来源。
- 链接：单列摘要卡；显示站点图标、标题、域名和摘要。
- AI 成果：单列或两列成果卡；显示成果类型、作者 Agent、Provider、模型和生成状态。
- 全部内容：按日期分段的混合卡片流，不使用普通设置列表。
- 分类页面允许通过顶部菜单切换内容类型；切换只改变卡片数据集，不改变页面结构。

除关键词搜索结果外，聊天记录页面内不使用传统列表排版。

### 3.3 卡片与预览

- 默认按日期分组，采用系统相册式网格和卡片混合布局。
- 图片显示缩略图；视频显示首帧、时长和生成状态。
- 文档显示文件类型 SVG、文件名和大小。
- 链接显示站点图标、标题、域名和摘要。
- AI 成果增加作者 Agent、模型和成果类型标识。
- 支持搜索文件名、消息文字、Agent 名称和来源标题。
- 支持多选后转发、导出、保存或删除当前会话引用。

点击记录进入统一预览页：

- 图片支持缩放和左右切换。
- 视频和音频支持本地播放。
- PDF、文本、Markdown、HTML 和常见办公文档使用统一预览框架。
- 无法直接预览的格式显示元数据和“使用其他应用打开”。
- 可定位到原消息。
- AI 成果可查看生成来源、输入素材、Agent、Provider、模型和任务状态。

### 3.4 页面状态

```text
search-idle
  顶部搜索框 + 空白内容区

search-results
  搜索框 + 关键词高亮列表

category-cards
  分类标题/切换入口 + 日期分段卡片

preview
  图片、视频、文件、链接或成果预览
```

页面状态由 `HistoryViewMode` 管理，搜索输入与分类选择互斥，避免同一屏同时出现高亮列表和卡片网格。

## 4. 用户导入文件

来源包括系统文件选择器、系统相册、相机、扫描、录音、分享扩展和其他 App“打开方式”。

持久使用的文件必须复制到 Halo App 沙盒。系统临时 URL 或安全作用域 URL 不能作为唯一存储路径。

```text
用户选择文件
→ 写入临时目录
→ 计算 SHA-256
→ 检查是否已经存在
→ 原子移动到资产目录
→ 生成缩略图或首帧
→ 写入 Asset
→ 创建 MessageAssetRef
```

## 5. 模型生成文件

生图、生视频、TTS、文档和代码任务统一使用以下状态：

```text
queued
→ generating
→ downloading
→ processing
→ completed

任一阶段
→ failed | cancelled
```

模型厂商返回临时下载 URL 时，完成后立即下载到本地沙盒。临时 URL 只作为任务字段保存并记录过期时间，不能成为历史消息的长期文件地址。

## 6. 数据模型

```text
Asset
  id
  origin(imported|generated|captured|shared)
  mediaType(image|video|audio|document|archive|other)
  mimeType, originalName, displayName
  byteSize, sha256
  localRelativePath, thumbnailRelativePath
  status
  createdAt, updatedAt

MessageAssetRef
  messageId, assetId, conversationId
  sortOrder, caption, createdAt

GenerationArtifact
  assetId, generationId
  agentId, providerId, modelId
  sourceAssetIds
  sourceMessageId, conversationId
  promptVersion
  remoteUrl, remoteUrlExpiresAt
  status, failureCode

AssetReference
  assetId
  ownerType(message|circlePost|memory|task|export)
  ownerId
```

约束：

- 数据库只保存沙盒相对路径，不保存设备绝对路径。
- `sha256` 用于内容去重，不代替用户可见文件名。
- 同一个 Asset 可被多个消息、圈层动态和任务引用。
- 删除消息默认只删除引用，不立即删除物理文件。
- 只有引用归零且不属于正在执行的任务时才能清除原文件。
- GenerationArtifact 必须能定位回来源消息和生成任务。

## 7. 本地目录

```text
Application Support/Halo/
├── assets/
│   ├── originals/
│   ├── generated/
│   ├── thumbnails/
│   └── previews/
├── temporary/
└── exports/
```

目录名不承担用户分类。日期、会话、Agent、来源和类型均由 SQLite 元数据组织。文件先写临时目录，再原子移动；缩略图、首帧和预览属于可重建缓存，原文件不能被普通缓存清理删除。

## 8. Agent 文件权限

Agent 不能默认浏览整个本地资产库。工具调用只接收 `assetId`，由 Runtime 校验授权后解析成短期可读路径。

授权范围：

- 仅本次任务。
- 当前会话持续可用。
- 加入群共享文件。
- 加入该 Agent 私有资料。

写入、覆盖、导出和删除均属于独立权限。删除和覆盖必须经过用户确认，不能只依赖提示词约束。

## 9. 设置中的存储管理

```text
设置
→ 本地数据与存储
```

展示总占用空间、图片与视频、文件、AI 生成成果、可重建缓存和最近增长。支持清理缓存、查找大文件、查看无引用资产、导出本地数据和清除全部本机数据。

设置页不承担日常查找文件；日常查找仍从具体会话的聊天记录进入。

## 10. 删除语义

用户必须能够区分：

1. 从当前消息移除。
2. 从圈层移除。
3. 删除所有引用并彻底删除本地文件。

彻底删除前展示引用位置和预计释放空间。正在被生成任务、导出任务或预览使用的资产延迟删除。

## 11. 验收标准

1. 单聊和群聊资料页都能进入“查找聊天记录”。
2. 能按全部、图片与视频、文件、链接和 AI 成果筛选。
3. 用户上传文件和模型生成文件都能在所属会话中找到。
4. 模型临时 URL 过期后仍能打开已完成的本地成果。
5. AI 成果能定位到来源消息、Agent 和生成任务。
6. 同一物理资产被多条消息引用时不会重复存储。
7. 删除单条消息不会误删其他位置仍在使用的文件。
8. Agent 未获授权时不能枚举或读取其他会话资产。
9. 设置页可以统计空间和清理缓存，但不出现第五个主 Tab。
10. 从“查找聊天记录”进入时只出现搜索框，未输入时内容区为空白。
11. 搜索结果使用列表展示，并对命中关键词进行高亮。
12. 图片与视频、文件、链接、AI 成果和全部内容均使用日期分段卡片。
13. 搜索列表与分类卡片不会在同一页面状态中混合出现。
