# 聊天详情与专家资料完整交互规格

版本：1.0

日期：2026-07-28

状态：原型已实现

## 1. 目标

Halo 延续即时通讯用户熟悉的操作路径，但把真人关系资料改造成 AI 专家、会话、模型、工具、记忆和圈层语义。

本轮补齐三个页面：

1. 单 Agent 聊天详情。
2. 群聊资料。
3. 专家资料。

核心验收原则：

> 凡是视觉上表达为可操作的文字、按钮、箭头、头像、图片、文件、开关、标签或卡片，都必须可点击，并产生页面跳转、弹层、预览、状态变化或明确反馈。

原型不允许出现只有悬停样式、箭头或按钮外观却没有响应的假入口。

## 2. 信息边界

### 2.1 聊天详情

聊天详情保存“当前会话”的状态：

- 消息免打扰。
- 置顶聊天。
- 重要消息提醒。
- 当前聊天背景。
- 查找、导出和清空当前聊天记录。

这些状态只影响当前会话，不修改专家的全局能力。

### 2.2 专家资料

专家资料保存“这个专家本身”的状态：

- 模型与 Provider。
- 提示词、性格和回答风格。
- 工具与数据权限。
- 共享事实和私有关系记忆边界。
- 主动消息。
- 圈层发布权限。
- 语音和视频能力。

修改专家资料后，所有使用该专家的新会话都读取新配置。

### 2.3 群聊资料

群聊资料同时包含：

- 通用会话管理。
- 群成员与群目标。
- 多 Agent 发言规则。
- 共享上下文。
- 自动总结和圈层发布。

## 3. 单 Agent 聊天详情

### 3.1 入口

单 Agent 对话右上角提供“更多”按钮，进入独立聊天详情页。

标题始终水平居中。右上角只保留一个更多按钮，不放语音或视频按钮；通话继续放在输入框“＋”菜单和专家资料页。

### 3.2 页面结构

#### 专家区

- 当前专家头像。
- 专家名称。
- 当前模型与状态。
- 点击头像或名称进入专家资料。
- “＋”按钮进入添加到群聊。

#### 内容区

- 查找聊天记录。
- 图片与视频。
- 文件。
- 链接。
- AI 成果。

“查找聊天记录”进入现有聊天资产分类页；其他快捷项直接打开对应分类。

#### 会话状态区

- 消息免打扰：开关，当前会话独立保存。
- 置顶聊天：开关，立即同步对话列表并显示反馈。
- 重要消息提醒：开关，开启后只提醒任务完成、失败、日程冲突和明确标记为重要的主动消息。

#### 外观区

- 设置当前聊天背景。
- 恢复默认背景。

背景选择使用底部弹层，提供默认浅灰、纸张、深蓝和从相册选择四种原型状态。选择后立即预览并保存。

#### 数据区

- 导出聊天记录。
- 清空聊天记录。
- 反馈专家问题。

导出显示格式选择：Markdown、JSON、包含附件的 ZIP。清空使用二次确认。反馈问题进入原因选择，不使用微信“投诉”文案。

## 4. 群聊资料

### 4.1 保留能力

- 成员头像网格。
- 添加 Agent。
- 群名称。
- 群目标。
- 主持 Agent。
- 默认发言规则。
- 共享上下文。
- 每次讨论自动总结。
- 总结发布到圈层。
- 清空群聊记录。
- 删除群聊。

### 4.2 新增能力

- 查找群聊记录。
- 图片与视频、文件、链接和 AI 成果快捷入口。
- 消息免打扰。
- 置顶群聊。
- 讨论完成提醒。
- 设置当前群聊背景。
- 导出群聊记录。

群成员头像可点击进入对应专家资料；添加卡进入专家选择；成员长按不在本轮原型范围内。

### 4.3 删除与清空

- 清空群聊记录：保留群、成员、规则和共享上下文，只删除消息引用。
- 删除群聊：删除群会话入口和群配置，进入二次确认。
- 两者必须使用不同文案、不同说明，防止误操作。

## 5. 专家资料

### 5.1 头部

- 专家头像。
- 名称。
- Provider 与模型。
- 当前状态。
- 一句话能力介绍。
- 更多按钮。

头像可点击进入大图预览；模型标签可点击进入模型配置；状态可点击查看当前任务和最近活动。

### 5.2 专家数据

提供独立“专家数据”入口，展示并允许编辑：

- 昵称与备注。
- 系统提示词。
- 性格与回答风格。
- 默认 Provider 和模型。
- 语音角色。
- 视频形象。
- 工具列表。
- 数据权限。
- 主动消息规则。
- 共享事实访问范围。
- 私有关系记忆。

敏感配置必须说明只保存在本机。API Key 不在该页展示。

### 5.3 圈层

专家资料展示“最近圈层动态”入口：

- 最近发布数量。
- 最近一条动态摘要。
- 点击进入只看该专家的圈层结果。
- 允许发布到圈层开关。

只看某专家是临时筛选结果，不改变圈层“不分类、按时间倒序”的主规则。

### 5.4 主操作

- 发消息。
- 语音通话。
- 视频通话。
- 添加到群聊。

语音或视频能力不可用时，不隐藏入口；显示原因和配置引导。

### 5.5 更多菜单

- 分享专家。
- 复制专家配置。
- 导出专家配置。
- 暂停主动工作。
- 从专家团移除。
- 反馈专家问题。

移除专家不自动删除历史会话；二次确认中必须解释数据后果。

## 7. 反馈规范

### 页面跳转

用于完整任务：

- 聊天详情。
- 专家资料。
- 专家数据。
- 聊天记录分类。
- 共享上下文。
- 语音或视频通话。

### 底部弹层

用于短选择：

- 背景。
- 导出格式。

## 8. 多 Provider 模型接入同步

本功能涉及的模型展示与选择遵循：

- `docs/02-architecture/06-multi-provider-model-access.md`
- `docs/02-architecture/05-toapis-provider-integration.md`

原型统一使用 `providerId + modelId` 作为模型引用，不把 ToAPIs 当作唯一入口：

- ToAPIs 是推荐聚合 Provider，可显示由 ToAPIs 返回的额度，但 Halo 不提供充值或支付。
- DeepSeek、OpenAI、Anthropic Claude、Google Gemini、自定义 OpenAI-compatible、本地模型、豆包端到端语音和 Vidu 均可独立配置。
- 多个 Provider 可以同时启用。
- 支持默认文字、图片、视频和 Router 模型。
- 支持单 Agent 模型覆盖。
- 同一群聊允许不同 Agent 使用不同 Provider。
- API Key 只进入本机安全存储；专家资料与导出包均不展示 Key。
- 无 Key、未配置、连接异常和本地服务离线使用不同状态说明，并提供测试、刷新、启停或候补 Provider 的恢复入口。

## 9. 原型实现记录

2026-07-28 已完成：

- 单聊详情、聊天记录分类、背景、导出、清空和反馈闭环。
- 群资料通用设置、成员资料跳转、内容分类与危险操作确认。
- 专家资料、专家数据、模型覆盖、圈层筛选和发布权限。
- 多 Provider 列表、详情、默认模型选择、异常态与群聊模型标识。
- 专家无圈层动态时显示明确空状态，不再出现数量与结果不一致。
- 关键操作契约测试和浏览器点击巡检。
- 提醒规则。
- 默认发言模式。
- 反馈原因。
- 更多菜单。

### Toast

用于已完成且不需要继续决策的动作：

- 已置顶。
- 已开启免打扰。
- 已复制配置。
- 已恢复默认背景。
- 已导出。

Toast 只做结果反馈，不拦截点击。

### 二次确认

用于：

- 清空聊天记录。
- 删除群聊。
- 从专家团移除。
- 暂停专家全部主动工作。

## 9. 视觉边界

- 保留用户熟悉的“头像区、分组设置、开关、箭头、危险操作置底”结构。
- 不复制微信深色主题、绿色品牌色、默认头像、图标、行高、间距和逐像素布局。
- 使用 Halo 靛蓝体系、Phosphor 图标、自有卡片间距和 iOS 安全区。
- 单聊详情、群资料、专家资料必须通过标题和内容清楚区分，不能只是换标题复用同一页。

## 10. 原型验收

1. 单 Agent 对话能进入聊天详情。
2. 聊天详情所有可操作元素都有反馈。
3. 群资料新增的通用会话管理均可操作。
4. 群成员头像能进入正确专家资料。
5. 专家资料能进入专家数据和该专家圈层结果。
6. 所有开关视觉状态、`aria-checked` 和 Toast 一致。
7. 所有危险操作都有二次确认。
8. 图片、文件和网页继续复用统一预览。
9. 不出现空链接、空按钮、假箭头或只改变鼠标样式的入口。
10. 所有页面横向溢出为 `0px`。
11. iOS 底部安全区、圆角和内容滚动不裁切。
12. 浏览器控制台 0 warning、0 error。
