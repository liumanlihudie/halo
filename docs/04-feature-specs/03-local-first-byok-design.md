# Halo 本地优先与 BYOK 功能设计

## 1. 产品原则

Halo 是无需注册的开源个人 AI 通讯工具。用户安装后直接进入对话，不创建 Halo 账号，不提供平台 Token、充值、订阅或支付。

- 对话、Agent、记忆、索引默认保存在本机。
- 用户自行配置 ToAPIs、厂商官方 API、自定义兼容服务或本地模型（BYOK）。
- API Key 只保存在 iOS Keychain / Android Keystore。
- 普通文字模型优先由 App 直连。
- 只有需要服务端签名、临时凭证或无法安全直连的能力才连接用户自托管的 Gateway。
- 导出数据包不包含 API Key。

## 2. 设置页

顶部使用“本地空间”资料卡，展示无账号、本地存储和可导出状态，以及 Agent、模型和记忆数量。

设置分为：

1. 模型服务：多个 Provider、默认文字/图片/视频模型、每 Agent 覆盖、豆包端到端语音。
2. 记忆与个性化：共享事实记忆、私有关系记忆、专家圈层发布。
3. 自托管与本地数据：Gateway、本地数据与备份、系统权限、Face ID 保护。
4. 开源项目：GitHub、许可证、版本。

不得出现账户中心、登录、退出、验证码、密码、充值、支付和删除账户。

## 3. 模型服务

MVP 首批内置模型服务：

- ToAPIs：聚合文字、图片和视频模型。
- DeepSeek、OpenAI、Anthropic、Google Gemini：使用用户自己的官方 Key。
- 自定义 OpenAI-compatible：填写 Base URL、Key 与模型配置。
- 本地模型：通过 Ollama、LM Studio、vLLM 等兼容服务连接。
- 豆包端到端语音：独立实时语音 Provider。

多个 Provider 可以同时启用。用户可以测试连接、保存配置、刷新模型列表、调整优先级、设置全局默认模型、覆盖单个 Agent 的模型并移除 Key。

密钥存储规则：

- 原型只模拟状态；正式 App 使用 Keychain / Keystore。
- 日志、SQLite、崩溃报告和导出包不得包含完整密钥。
- UI 默认掩码显示，复制或显示属于显式操作。
- 移除 Provider 时只删除对应密钥和配置，不删除历史消息。

具体接口、错误映射和异步媒体状态机见 [ToAPIs 模型中转站接入方案](../02-architecture/05-toapis-provider-integration.md)。

## 4. 自托管 Gateway

Gateway 是可选组件，不是 Halo 官方 SaaS。用户可以通过 Docker 部署到自己的电脑、NAS 或服务器。

适用场景：

- 为实时语音签发短期凭证。
- 为 Vidu 等服务完成服务端签名。
- 隐藏不允许下发到移动端的长期密钥。
- 统一处理跨域、流式协议适配和审计。

App 保存 Gateway URL 和可选访问令牌。未配置 Gateway 时，所有可直连 Provider 和本地功能仍可使用。

## 5. 本地数据与迁移

- SQLite：会话、消息、Agent、群聊、记忆、任务状态和结构化索引。
- App 沙盒：图片、语音、视频、文件和缩略图。
- Keychain / Keystore：Provider 密钥和 Gateway 令牌。

日常文件查找不使用独立文件管理主页面。用户从具体单聊或群聊资料进入“查找聊天记录”，查看图片与视频、文件、链接和 AI 成果；设置页只提供空间统计、缓存清理、导入导出和清除本机数据。

模型生成成果必须在完成后下载到本地沙盒，并保存来源消息、Agent、Provider、模型和输入素材引用。详细规则见 [聊天记录与文件资产设计](04-chat-history-assets-design.md)。

导出包包含 JSON/SQLite 数据与附件清单，可用于迁移和备份；不包含任何密钥。导入前显示摘要，冲突默认生成副本，不静默覆盖。

清除本机数据必须二次确认。清理缓存与清除业务数据分开，且清除业务数据默认保留 Keychain 密钥，用户可在模型服务中单独移除。

## 6. 验收标准

1. 首次启动无需登录即可进入对话。
2. 设置页可进入模型服务、本地数据和自托管 Gateway。
3. Provider 可测试、保存和移除。
4. 未配置密钥时给出本地错误，不发起请求。
5. 导出说明明确排除 API Key。
6. 清除本机数据必须二次确认。
7. 原型源码不包含账户、密码、验证码、平台 Token 或支付入口。
8. 上传文件和模型生成成果可从所属会话的聊天记录分类中找到。
9. 不增加独立文件管理 Tab。
10. ToAPIs 连接测试不发送用户对话，成功后显示当前 Key 的可用模型。
11. 设置页能展示并修改默认文字、图片和视频模型。
12. DeepSeek 等官方 Provider 不依赖 ToAPIs Key，也可以独立完成调用。
13. 同一群聊允许不同 Agent 使用不同 Provider。
